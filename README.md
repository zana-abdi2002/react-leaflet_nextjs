## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/germany-train-stations-map.git
cd germany-train-stations-map

# Install dependencies
pnpm install

# Development server
pnpm dev

# Production build
pnpm build
pnpm start
```

Visit `http://localhost:3000` to see the map in action.
